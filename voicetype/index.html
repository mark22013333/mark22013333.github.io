VoiceType

macOS／Windows 語音轉文字桌面 App，離線辨識加 AI 潤稿。

按全域熱鍵（macOS 預設 Cmd+Shift+O）開始錄音，語音辨識預設在本機完成。停止後可以交給 AI 依「潤稿風格」整理成會議紀錄、任務清單、郵件草稿等書面文字，結果預設直接貼到游標所在位置。不錄音時也能貼上文字直接潤稿。

下載 GitHub

需求：macOS 10.15 以上（Apple Silicon）或 Windows 10 以上（x64）；AI 潤稿預設使用 Claude Code CLI，也可改用其他 LLM Provider

// 功能

錄音、辨識、潤稿都在一條工具列上

平常只是一條常駐工具列，不佔螢幕空間；停止錄音後才展開面板顯示逐字稿與結果。

01 · 錄音錄音中就看得到辨識文字

按全域熱鍵或工具列的 REC 開始錄音。錄音中工具列顯示計時、目前的辨識模式與模型、音量波形，以及最新一段辨識出來的文字。

  • 熱鍵預設 macOS Cmd+Shift+O、Windows Ctrl+Shift+O，可在「設定 → 快捷鍵」更換
  • 觸發方式可選「按一下開始／再按一下停止」或「按住錄音／放開停止」
  • ⏸ 按鈕暫停、STOP 停止
  • 工具列寬度可以拖曳調整
VoiceType — 錄音中

02 · 自動潤稿停止錄音後自動整理（需先開啟）

停錄後是否送 AI 潤稿，由「設定 → 錄音」的兩個開關決定，兩者預設都是關閉：沒開的話，結果就是原始逐字稿。

  • 日常即時聽寫：每次定稿後自動 AI 潤稿，不受秒數門檻限制
  • 會議／離線錄音：停止後自動 AI 潤稿；低於門檻秒數（預設 60 秒）的錄音直接輸出原文，不呼叫 LLM
  • 逐字稿超過 5000 字會自動分段整理
  • 沒開自動潤稿時，也可以在展開面板按「AI 整理」手動送出
VoiceType — AI 整理結果

03 · 潤稿風格8 種內建風格，也能自訂

潤稿風格決定 AI 整理的口氣與格式，不會改變原始逐字稿、辨識模型或 LLM Provider。

  • 內建：日常自然（預設）、會議紀錄、任務清單、郵件草稿、簡短訊息、正式語氣、輕鬆語氣、提示詞最佳化
  • 可以新增自訂風格，或從內建風格複製後修改
  • 每種風格的 prompt 都能檢視（清單只顯示前幾行）
VoiceType 設定 — 潤稿風格

04 · 輸出方式結果直接貼到游標位置

預設會把結果寫進剪貼簿、模擬 Cmd+V／Ctrl+V 貼到目前游標所在位置；原本剪貼簿若是文字，貼上後會還原。也可以在「設定 → 一般 → 辨識結果輸出」改成「只複製到剪貼簿」。

  • macOS 上自動貼上需要「輔助使用」權限；貼上失敗時工具列會顯示錯誤與「開啟權限設定」按鈕，結果仍可在展開面板複製
  • 原本剪貼簿若是圖片、檔案或空白，不會還原，結果會留在剪貼簿（不會另外提示）；文字還原失敗時工具列會提示
  • AI 潤稿的 LLM Provider 與模型也在「一般」頁設定；用 Claude CLI 時可選 Haiku／Sonnet／Opus，不指定則由 Claude CLI 自動選擇
VoiceType 設定 — 一般

05 · TYPE 模式不錄音也能潤稿

按工具列的 TYPE，直接貼上文字進行 AI 潤稿，套用目前的潤稿風格與模型設定。下圖用的是「簡短訊息」風格；潤稿完成後同樣依「辨識結果輸出」設定自動貼上。

  • 輸入框右下角即時顯示字數
  • 超過 500 字會提醒「文字量較大，AI 處理可能產生較高費用」
VoiceType — TYPE 模式

06 · 本機辨識語音辨識預設在本機完成

辨識引擎跑在本機：Whisper（whisper.cpp），以及 SenseVoice、Paraformer 等 sherpa-onnx 模型。模型在「設定 → 模型管理」下載，每個模型標出大小、品質、速度與適用情境。

  • 也可以在模型管理頁連線到外部的 ASR 伺服器（選用），連上後辨識改由該伺服器處理
  • 「日常即時聽寫」：純麥克風錄音時可改用專用的中英串流模型，說話時立即顯示文字；會議模式仍用高品質模型
  • 辨識前做高通濾波＋RNNoise 降噪（兩者一起在「設定 → 錄音」的降噪開關控制）
  • 錄音檔（.wav）和逐字稿（.txt）存在可自訂的目錄，展開面板的「開啟檔案位置」可直接打開
VoiceType 設定 — 模型管理

// AI 潤稿用哪個模型

預設 Claude CLI，也可以換別家

AI 潤稿可以選 5 種 LLM Provider，在「設定 → LLM Provider」切換。Provider、模型、輸出方式都是全域設定，切換潤稿風格不會改變它們。

用免費額度的 Provider 錄音超過 10 分鐘時，工具列會提醒長逐字稿可能受速率或輸入長度限制；部分整理失敗時，失敗段以原文保留。

Antigravity CLI（訂閱）   走 Google AI 訂閱
Google Gemini             免費 tier（15 RPM / 1500 RPD）
Groq（Llama / Mixtral）   免費 tier（限額但持續）

// 安裝

從 Releases 下載安裝檔

前往 GitHub Releases 下載最新版本：macOS（Apple Silicon）是 VoiceType_x.x.x_aarch64.dmg，Windows（x64）是 VoiceType_x.x.x_x64-setup.exe。

# 把 VoiceType 拖入 Applications 資料夾後，在終端機執行：
$ xattr -cr /Applications/VoiceType.app
  • macOS：下載 .dmg，開啟後將 VoiceType 拖入 Applications 資料夾，再執行上面的指令。
  • Windows：Edge 若顯示「不常下載」，在下載項目旁的選單依序選「保留」→「顯示更多」→「仍要保留」；執行安裝程式時若 SmartScreen 顯示「Windows 已保護您的電腦」，選「其他資訊」→「仍要執行」。
  • 仍然閃退時，到 %APPDATA%\com.voicetype.app\logs\ 取得 bootstrap.log 與最新的當機記錄，到 GitHub Issues 回報。

第一次開啟之後

  • 工具列提示「尚未載入語音模型」時，到「設定 → 模型管理」下載一個模型。
  • 想要停錄後自動潤稿，到「設定 → 錄音」開啟對應的開關。
  • 在「設定 → 一般」確認 Claude CLI 路徑（會自動偵測）與 LLM Provider；改用其他 Provider 到「設定 → LLM Provider」。
  • macOS 上全域熱鍵與自動貼上需要「輔助使用」權限，工具列會提示並提供開啟設定的按鈕。

// 使用前須知

安裝與使用前請先知道

  • macOS 版尚未取得 Apple 開發者簽名macOS 會顯示「已損毀，無法打開」。這不是檔案損壞，而是 Gatekeeper 的限制；首次開啟前執行 xattr -cr /Applications/VoiceType.app，每次更新版本後需要重新執行一次。
  • Windows 安裝檔尚未使用付費的程式碼簽章憑證發行者會顯示為「不明」，SmartScreen 也可能把新版標示為不常下載。這不代表檔案已損壞；請只從 GitHub Releases 下載，來源不明的檔案請取消安裝。
  • Windows／VMware 啟動後可能閃退尤其在 VMware 的 Windows 11 虛擬機器內，可能是 WebView2 與虛擬顯示卡的硬體加速相容性問題。執行 setx VOICETYPE_SOFTWARE_RENDERING 1 後重新啟動即改用軟體繪圖；改回執行 setx VOICETYPE_SOFTWARE_RENDERING 0。
  • 停錄後自動潤稿預設是關閉的要在「設定 → 錄音」開啟。會議／離線錄音另有秒數門檻（預設 60 秒），低於門檻直接輸出原文。
  • 自動貼上會暫時佔用剪貼簿原本剪貼簿若是文字，貼上後會還原（還原失敗時工具列會提示）；若是圖片、檔案或空白則不會還原，結果會留在剪貼簿。macOS 上需要「輔助使用」權限，否則貼上會失敗（結果仍可在展開面板複製）。
  • macOS 版只提供 Apple SiliconReleases 上的 macOS 安裝檔是 aarch64 版；Windows 為 x64。
